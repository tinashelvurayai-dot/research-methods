# EXAM Mode - User Guide

## What is EXAM Mode?

EXAM Mode is a dedicated examination preparation section featuring 60+ comprehensive exam-level questions extracted from real National Diploma past papers. It provides focused, realistic practice for your automation exams.

## How to Access EXAM Mode

1. **Log in** to your account
2. Go to your **Dashboard**
3. Look for the **"EXAM Mode"** card (orange/red banner)
4. Click **"Start Exam"** button

Alternatively, navigate directly to: `/exam-mode`

## How to Use EXAM Mode

### Viewing Questions
- **Click the card** to flip between question (front) and answer (back)
- Questions are presented one at a time
- Difficulty level is shown (Easy 🟢 / Medium 🟡 / Hard 🔴)

### Managing Your Study
- **⭐ Bookmark**: Click to save important questions for later review
- **🚩 Mark for Review**: Flag questions you find difficult or want to revisit
- **✓ Mark Mastered**: Track which questions you've fully understood

### Navigation
- **← Previous**: Go back to the previous question
- **🔄 Reset**: Start from the beginning (clears your progress)
- **Next →**: Move to the next question

### Progress Tracking
Watch your progress in real-time:
- **Current Question**: e.g., "12/60" shows you're on question 12 out of 60
- **Progress Bar**: Visual indicator of how far through the exam you are
- **Reviewed Count**: Number of questions you've looked at
- **Marked Count**: Number of questions flagged for review

### Completion
When you reach the last question:
- See a completion message
- Return to Dashboard
- Or start over to practice again

## Question Categories

EXAM Mode covers all major automation topics:

### 1. **Fundamentals** (10 questions)
- Industrial Automation definition and benefits
- Control system types (SCADA, DCS, DDC, PLC)
- Hardware components (Actuators, Sensors, Transducers)

### 2. **Robotics** (8 questions)
- Robot components and architecture
- Sensor types and applications
- Robotic measurement and control

### 3. **Control Systems** (6 questions)
- System signals and feedback
- Stability analysis (Nyquist, Bode plots)
- Performance metrics (gain margin, phase margin)

### 4. **Industrial Systems** (6+ questions)
- Automation types (Fixed, Programmable, Flexible)
- PLCs: programming and applications
- Motors and actuators

### 5. **Advanced Topics** (20+ questions)
- Transducers and measurement
- Communication protocols
- Integration and control

## Tips for Success

✅ **Start Systematically**: Begin with Easy questions to build confidence

✅ **Mark Difficult Questions**: Use the 🚩 flag to focus on weak areas

✅ **Review Bookmarks**: After completing all questions, review your bookmarked questions

✅ **Repeat Practice**: Multiple passes through EXAM Mode improve retention

✅ **Focus on Mastery**: Mark questions as mastered when you can answer them confidently

✅ **Read Answers Carefully**: Understand not just the answer, but why it's correct
