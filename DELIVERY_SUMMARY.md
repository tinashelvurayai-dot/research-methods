## How to Deploy

### **Quick Deploy (Recommended)**
```bash
cd /vercel/share/v0-project
npx supabase db push
```
This applies all migrations and populates flashcards automatically.

### **Manual Import**
1. Start dev server: `npm run dev`
2. Navigate to `/admin-setup`
3. Create admin account
4. Go to Admin Dashboard → Content tab
5. Click "Bulk Import"
6. Copy content from `flashcard-seed-expanded.md`
7. Click "Import" button

### **Production Deployment**
1. Connect repository to Vercel
2. Commit changes to feature branch
3. Push to GitHub
4. Vercel automatically applies migrations
5. Database updated on deployment
