# Quick Start Guide - Exam Cards System

## 📚 Accessing Your Exam Cards

### Main Features
1. **Dashboard** - Overview of all topics with progress tracking
2. **Exam Mode** - Full set of 150+ exam-level questions
3. **Topic Learning** - Deep dive into individual topics with card-by-card revision
4. **Search** - Find specific questions across all topics
5. **Bookmarks** - Save important questions for later review

## 🎯 How to Use

### Start Exam Mode
1. From Dashboard, click **"Start Exam"** button
2. You'll see exam-level questions covering all topics
3. Click the card to flip between question and answer
4. Use **Previous/Next** buttons to navigate
5. Mark cards as:
   - **Mastered** - Questions you've got down
   - **Needs Practice** - Questions to review
   - **Bookmarked** - Save for later

### Learn Specific Topics
1. From Dashboard, select any topic card
2. Click **"Learn"** to start revising that topic
3. Track your progress with the mastery bar
4. Card-by-card feedback with "Got It" or "Needs Practice"

### Search & Filter
1. Click **"Search all cards"** from Dashboard
2. Type your search query
3. Find questions across all topics instantly

### Track Progress
- **Progress Bar** shows mastery completion
- **Reviewed Counter** tracks studied cards
- **Mastered Counter** shows completed cards
- **Marked Counter** shows flagged questions

## 🔧 Troubleshooting

### Cards Not Loading
1. Check your internet connection
2. Refresh the page (F5)
3. Clear browser cache
4. Try again in a few moments

### Slow Performance
1. Close other browser tabs
2. Disable browser extensions
3. Try a different browser
4. Check your internet speed

### Lost Progress
- Your progress is saved automatically
- It syncs across devices if logged in
- Bookmarks and mastery data are preserved

## 💡 Tips for Success

1. **Start Easy** - Begin with "easy" difficulty cards
2. **Build Momentum** - Mark cards as you master them
3. **Target Weak Areas** - Focus on "Needs Practice" cards
4. **Use Bookmarks** - Save tricky questions
5. **Practice Regularly** - Consistent revision improves retention
6. **Mix Topics** - Alternate between different topics for variety

## 📝 Card Structure

Each card contains:
- **Question** - Clear, exam-style question
- **Answer** - Complete, detailed answer with explanations
- **Difficulty** - Easy/Medium/Hard rating
- **Topic** - Category for organization
